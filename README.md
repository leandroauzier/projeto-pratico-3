# LENS Materiais de Escritório — Site Institucional

Trabalho acadêmico: site institucional com vitrine virtual para empresa fictícia **LENS Materiais de Escritório Ltda.**, desenvolvido com Next.js, TypeScript e Tailwind CSS.

*Criado por: `Leandro Sobrinho Auzier`*

## Sobre o projeto

Site criado como atividade prática para demonstrar conceitos de desenvolvimento web moderno e responsivo. A empresa fictícia atua no segmento de materiais de escritório, papelaria, informática e suprimentos.

**Seções:**
- Página inicial com apresentação da empresa
- Vitrine virtual com 4 linhas de produtos (Papelaria, Informática, Escritório, Suprimentos)
- Formulário de contato e solicitação de orçamento
- FAQ com perguntas frequentes
- Informações sobre estrutura tecnológica do projeto

## Tecnologias

- [Next.js](https://nextjs.org) (App Router)
- TypeScript
- Tailwind CSS

## Como rodar

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).
